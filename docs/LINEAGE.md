# Lineage

**ResearchersHub** is a science-first product from [ItsNotAI Labs](https://github.com/ItsNotAILABS).

It inherits runtime DNA from **POCKET** (local multi-agent host: Edge desk, sessions, sellable API, always-on host). The public product identity, skills, Atlas graph, multi-model router, and coding-agent surface are **ResearchersHub**.
