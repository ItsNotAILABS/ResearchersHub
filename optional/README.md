# Optional extras

**Not required** to run or understand ResearchersHub.

| Folder | What |
|--------|------|
| `desktop-electron/` | Electron desktop shell experiment |
| `vendor/` | Bundled experimental libraries |
| `releases/` | Desktop packaging metadata |
| `web/` | Extra web scaffold |

Core product = `src/` + `skills/` + `docs/` + `scripts/` (non-legacy).
